# YOSHI Health Tracker

①健康 ②筋肉トレーニング ③体重を上げる ― この3つを目標に、食事・トレーニング・体重を一元管理する
ブラウザ完結型の記録アプリです。サーバーやビルド不要、`index.html` を開くだけで使えます。

## 使い方

1. `index.html` をブラウザで開く(スマホのホーム画面に追加すると簡易アプリのように使えます)
2. 「設定」タブで身長・年齢・性別・活動レベル・増量目標を入力して保存
3. 「体重」タブで今日の体重を記録(初回は必須。以後は毎日〜数日おきに記録)
4. 「食事」タブで食べたものを記録(写真は記録用として添付可能、栄養は手入力)
5. 「筋トレ」タブで種目・セット数・重量を記録
6. 「今日」タブでカロリー・たんぱく質・脂質・炭水化物の目標に対する達成率を確認

## 目標値の計算方法

- 基礎代謝(BMR): Mifflin-St Jeor式
- 消費カロリー(TDEE) = BMR × 活動レベル係数
- 摂取目標カロリー = TDEE + 増量分の上乗せカロリー(設定タブで調整、デフォルト +400kcal)
- **たんぱく質目標 = 体重(kg) × 2g**(指定どおり)
- 脂質目標 = 摂取目標カロリー × 設定した割合(デフォルト25%) ÷ 9
- 炭水化物目標 = 残りのカロリーから算出

体重を記録するたびに基準体重が更新され、目標値も自動的に再計算されます。

## データの保存場所

すべてのデータ(プロフィール・食事記録・トレーニング記録・体重記録・写真)は、
このアプリを開いているブラウザの `localStorage` にのみ保存されます。
外部サーバーへの送信は一切行いません。

- 機種変更・ブラウザ変更の前には「設定」タブの **JSONをエクスポート** で必ずバックアップしてください
- 別の端末やブラウザで使う場合は、エクスポートしたJSONを **JSONをインポート** で読み込んでください
- ブラウザのキャッシュ削除・シークレットモードではデータが失われるので注意してください

## 写真について

食事の写真はその場でブラウザ内で自動リサイズ(最大480px・JPEG圧縮)してから保存されるため、
現状は記録・見返し用の添付画像としてのみ利用します(自動での栄養解析は行いません)。
カロリー・たんぱく質などは撮影後にご自身で入力してください。

## ファイル構成

```
index.html      画面構成(ダッシュボード/食事/筋トレ/体重/設定の5タブ)
css/style.css   スタイル(ライト/ダークモード自動対応)
js/app.js       ロジック(データ保存・目標計算・グラフ描画など、外部依存なし)
docs/           別プロジェクト(SNS/YouTube自動収集のn8nワークフロー)のドキュメント
```

外部ライブラリやビルドツールには依存していないため、オフラインでもそのまま動作します。
